Download ThatSoundsLikeMe

ThatSoundsLikeMe lets you imitate a sound with your voice and search for similar sounds on Freesound. The microphone recording and embedding model run locally; see the privacy policy for details.

Desktop beta releases for macOS and Windows, with release notes and SHA-256 checksums, are published on the GitHub releases page and made available through MuseHub. Production releases will also include an SBOM.

macOS releases are signed and notarized by Apple using Queen Mary University of London's Developer ID identity. Windows releases are currently unsigned. A Certum Open Source Code Signing certificate is awaiting issuance and activation for future free, open-source Windows releases; see the Code signing policy.

Installation and removal

On Windows, run the downloaded installer and choose the standard per-user installation. Use Windows Settings → Apps to uninstall. On macOS, open the signed and notarized disk image, move ThatSoundsLikeMe to Applications, and delete it from Applications to uninstall.

Research project

ThatSoundsLikeMe won Best app for Muse Hub and the Other challenge at the 2025 London Music Technology Hackathon. Its underlying model was developed from the team's first-place entry in the Audio Engineering Society (AES) AIMLA Querying by Vocal Imitation Challenge 2025. Optional research data collection is covered by Queen Mary Ethics of Research Committee reference DSEECS25.073.
