Code signing policy

ThatSoundsLikeMe release downloads are published from the public project repository.

Current signing status

macOS releases are signed with Queen Mary University of London's Apple Developer ID identity, notarized by Apple, and stapled before publication.

Windows releases are currently unsigned. Windows may show a SmartScreen warning; only install a Windows build downloaded from an official release and verify its checksum.

Release responsibilities

  • Authors: chrispla, mimbres, and chymaera96.
  • Reviewer for outside contributions: chrispla.
  • Signing approver: chrispla.

Release downloads include SHA-256 checksums. An SBOM will be included in future production releases. See the privacy policy for data-handling information.

Planned Windows signing

The project is preparing an application to SignPath Foundation. If it is accepted and signing is enabled, signed Windows releases will carry the acknowledgement “Free code signing provided by SignPath.io, certificate by SignPath Foundation.” This statement does not apply to the current unsigned Windows beta.
