Code signing policy

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Project roles

  • Authors: chrispla, mimbres, and chymaera96.
  • Reviewer for outside contributions: chrispla.
  • Release and signing approver: chrispla.

Build and release

Windows releases are built on GitHub-hosted runners from the public source repository. The project executable and final installer are submitted separately for signing and every signing request requires manual approval. macOS releases are signed with Queen Mary University of London's Apple Developer ID identity, notarized by Apple, and stapled before publication.

Release downloads include checksums, a software bill of materials and this policy. The privacy policy is available at thatsoundslike.me/privacy.html.
