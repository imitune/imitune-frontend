Code signing policy

ThatSoundsLikeMe release downloads are published from the public project repository.

Current signing status

macOS releases are signed with Queen Mary University of London's Apple Developer ID identity, notarized by Apple, and stapled before publication.

Windows releases beginning with v1.0.3 are Authenticode-signed and timestamped using the project's Certum Open Source Code Signing in the Cloud certificate. Only install a Windows build downloaded from an official release and verify its checksum.

Release responsibilities

  • Authors: chrispla, mimbres, and chymaera96.
  • Reviewer for outside contributions: chrispla.
  • Signing approver: chrispla.

Production release downloads include SHA-256 checksums and an SBOM. See the privacy policy for data-handling information.

Windows signing certificate

Certum has issued an active Open Source Code Signing in the Cloud certificate to Open Source Developer Christos Plachouras. Windows releases from v1.0.3 onward are signed with this certificate and carry a trusted timestamp.
