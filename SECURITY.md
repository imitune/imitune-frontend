# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Email
`c.plachouras@qmul.ac.uk` with a concise description, reproduction steps, and
any evidence that helps us assess impact. We will acknowledge reports within
seven days and coordinate a fix before public disclosure where appropriate.

## Supported releases

Only the latest production web deployment and the latest desktop release are
supported. The retired Electron prototype and historical builds are not
supported.

## Release controls

Desktop release artifacts are built from the public source repository, tested
before publication, and approved by the project release approver. Dependencies
are audited in CI and release artifacts include checksums and an SBOM.
